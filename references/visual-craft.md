# 视觉工艺与动感规范（可执行清单）

制作任何 MathAPP 风格交互图时**必须**对照本清单。

相关：色值与外壳见 `mathapp-conventions.md`；流程见 `workflow.md`；总验收见 `acceptance.md`。

---

## 0. 嵌入页 vs 独立页（先选档）

| | **嵌入课程页（默认）** | **独立演示/调试页（可选）** |
|---|---|---|
| 用途 | `@interactive` / `@aside` / numerical 进站 | 本地验收、录屏、调参 |
| 外壳 | 对齐 Riemann / NumericalFigure / SpaceFigure：图 + 薄控件条 | 可略宽，仍用 figureTheme |
| 标题 | 无营销大标题；课程正文已有标题 | 至多一行小标题 |
| 读数 | **一行极简**或折叠；禁止默认长侧栏 | 可展开详细 readout |
| 文案 | 不写说明书式长文 | 可保留简短数学边界提示 |
| 控件 | 少：选项、短参数、复位/单步 | 可加调试开关、tour |
| 装饰 | 禁止页面级光斑底、badge、厚阴影墙 | 仍禁止花哨；可略增留白 |
| 动效 | 服务理解，克制；不抢课程阅读 | 可稍完整 |

**默认按嵌入档验收。** 独立页不得作为「站内应有的样子」交付。

嵌入页额外禁止：

- [ ] 无额外大标题 / 副标题长文 / 营销 badge
- [ ] 无堆叠状态文案（「播放中·竖线射出·anim%」等）
- [ ] 无仪表盘式多面板；读数默认不占整列侧栏
- [ ] 控件不超过「看懂 + 操作」所需；能合并则合并
- [ ] 无说明墙；几何直觉靠图，不靠段落

---

## A. 图层顺序（背景 → 焦点）

1. [ ] **背景**：纸色 `#fcfdfc`（嵌入页勿用花哨页面渐变）
2. [ ] **网格**：极淡（`#e3e8e4` @ 15–25% 或 lineWidth≤0.6）
3. [ ] **坐标轴 / 辅助线**：`#7a847e`
4. [ ] **区域填充**（可选）：透明度 ≤ 0.12；禁止彩虹
5. [ ] **主曲线 / 主向量**：墨绿 `#245443` 等主题色；`lineCap/Join = round`
6. [ ] **轨迹 / 次向量**：暖棕 `#b5763a` 等；历史可渐隐
7. [ ] **焦点与标注**：点 + 白描边；标签避让 ≥ 8px；**标注尽量少**

---

## B. 抗锯齿与清晰度

1. [ ] Canvas：`width/height = css * dpr`，`setTransform(dpr,…)`；禁止低清拉伸
2. [ ] 静态/少量路径优先 SVG
3. [ ] 线宽、点半径、圆角整页一致
4. [ ] 刻度等宽 9–10px；轴名斜体衬线 12px；UI 系统无衬线

---

## C. 曲线采样

1. [ ] 线性：采样 ≥ 视口宽/4（通常 ≥ 80）
2. [ ] 非线性：≥ 400 或自适应加密
3. [ ] 出界重开 path，避免斜穿伪影
4. [ ] 150% 放大无明显折线感

---

## D. 色板与渐变

沿用 figureTheme；渐变**克制**。

| 用途 | 建议 |
|---|---|
| 主色 / 向量 a | `#245443` |
| 次色 / 向量 b | `#b5763a` |
| 第三色 / 向量 c | `#3f6e8c` |
| 结果 / 法向 / 叉积 | `#a4493f` |
| 面填充 | 对应色 alpha ≤ 0.12（嵌入）/ ≤ 0.18（独立） |
| 按钮 | 墨绿主按钮 / 浅底次要；勿花哨渐变按钮组 |
| 卡片 | 嵌入页：细边即可，阴影极弱或无 |

---

## E. 排版与控件

### 嵌入页（默认）

1. [ ] 模块宽度跟随课程栏（常见 max-width ≈ 640–760px），不强迫展示站宽布局
2. [ ] **无侧栏说明书**；公式放控件行附近**一行** KaTeX
3. [ ] 模式：紧凑分段控件，勿大卡片墙
4. [ ] 主操作：复位；需要时再加单步/播放
5. [ ] 读数：一行等宽；详情折叠
6. [ ] 图例：能靠颜色区分则省略文字图例

### 独立调试页（可选）

7. [ ] 可用稍详 readout，但仍 figureTheme、无营销头
8. [ ] 与嵌入页共用同一绘制内核，仅壳不同

---

## F. 数学符号（TeX）与标注避让

### TeX（强制）

1. [ ] 公式行、读数中的数学记号、向量名用 **KaTeX**（`\mathbf{a}`、`\times`、`|\mathbf{a}\times\mathbf{b}|` 等）
2. [ ] 禁止交付态长期纯文本冒充公式（`a×b` 作主读数不可接受）
3. [ ] Canvas/WebGL 上的数学标签：优先 **绝对定位 DOM + KaTeX**；勿依赖不清晰的 `fillText` 伪公式
4. [ ] KaTeX CSS/JS 与本站一致或 CDN 同源策略写明；离线回退仅临时

### 遮挡（注意事项 · 验收必查）

1. [ ] **符号与图形不得互相遮挡**：标签不压平行四边形/六面体内部、轨迹中段、箭头杆中部、交点簇
2. [ ] 标签默认在箭头尖端外侧；冲突则换侧 / 沿法向自动偏移（≥ 8–12px）
3. [ ] 需要时用**半透明纸色底板**（alpha ≈ 0.75–0.85），提高可读且不糊住几何
4. [ ] 不与底部提示、控件条、模式切换重叠
5. [ ] 嵌入页少标：向量名 + 结果记号即可；详细公式放控件旁**一行** KaTeX
6. [ ] 旋转相机/改参数后重新测位置；固定一帧验收「无挡关键几何」

---

## G. 时间函数与变速

1. [ ] 禁止匀速 clock→几何（除非刻意表达匀速物理量）
2. [ ] 生长/射出用 **ease-out**；整段可用 ease-in-out
3. [ ] `easeOutCubic(t)=1-(1-t)^3`
4. [ ] 单段约 500–800ms（speed=1）

---

## H. 轨迹与几何动效

1. [ ] 只插值当前段几何，不伪造中间计算结果
2. [ ] 历史可渐隐；当前段高亮
3. [ ] 参数变更打断动画并重建
4. [ ] 嵌入页：尾迹/拖影弱；体积/面积填充淡入即可

---

## I. 播放节奏

1. [ ] 播放 = 推进 animT，非跳步闪现
2. [ ] 多模式 tour 仅独立页或折叠入口；嵌入页默认不自动连环演示
3. [ ] `document.hidden` 暂停；只用 rAF；目标 ~60fps

---

## J. 三维 / 向量几何（SpaceFigure 档）

1. [ ] **优先**本站 `space3d` / `SpaceFigure` 交互习惯：拖动旋转视角、复位相机；相机 ≠ 改向量数据
2. [ ] 确需 Three.js 时可用 CDN ESM，材质色仍锁 figureTheme；光照柔和，避免塑料高光喧宾
3. [ ] 深度排序或透明面：平均深度可接受；复杂相交勿假装物理正确
4. [ ] 平行四边形 / 平行六面体：边清晰、面 alpha 低；体积符号用填充色冷暖或符号前缀区分，勿靠文字墙
5. [ ] 法向 / 叉积箭头与底面区分色；右手定则提示**短、可关、默认克制**（一次弧线即可）
6. [ ] 坐标盒/网格极淡；可关
7. [ ] 读数一行：如 `|a×b|=…` 或 `V=a·(b×c)=…`（含符号）

---

## K. 交付前自检

### 嵌入页（默认，全勾）

1. [ ] 看起来像本站 interactive/aside，而非独立产品页
2. [ ] 无营销大标题 / badge / 说明书长文
3. [ ] 读数一行或折叠；无信息过载
4. [ ] 控件少而够用
5. [ ] DPR 清晰；曲线/边无粗糙折线感；网格极淡
6. [ ] 动效服务直觉，不抢阅读
7. [ ] 参数改动打断播放
8. [ ] 主题色仅 figureTheme
9. [ ] 数学符号均为 KaTeX（非纯文本冒充）
10. [ ] 标签/公式未遮挡关键几何与控件

### 独立页另加

9. [ ] 详 readout / tour 与嵌入壳分离或可开关
10. [ ] hidden 时暂停；无多重 rAF 泄漏

---

## L. 反例（禁止）

- 低清 canvas CSS 放大
- 稀疏折线主曲线；粗网格抢戏
- 匀速跳步动画冒充连续几何
- 过强发光、彩虹、粒子、镜头抖动
- **自造仪表盘、双栏长读数当站内默认**
- **页面级装饰光斑 + badge + 大标题**当嵌入模块
- **纯文本长期代替 KaTeX 公式/向量记号**
- **标签压在平行四边形 / 六面体 / 轨迹 / 控件上**
