# 五层架构与制作流程

## 五层

1. **数学层**：对象、定义域、前提、精确/近似含义、误差、独立验算值。
2. **状态层**：参数、选择、步骤索引、播放、种子。算法生成状态；渲染只读。
3. **场景层**：点/线/面/节点/数组格等，**稳定 ID**；布局坐标可与算法状态分存。
4. **呈现层**：SVG / Canvas /（扩展）WebGL；负责坐标、颜色、插值动画。
5. **验收层**：数学不变量、真实点击/拖动/单步、固定截图、卸载清理。

播放进度 ≠ 数学时间。离散两帧之间的视觉过渡不得伪造中间计算结果。相机旋转只改观察，不改数据。

## 交付形式选型

| 形式 | 默认做法 | 何时用 |
|---|---|---|
| **网页实时交互**（默认） | Vue 组件或自包含 HTML；SVG/plane2d；复杂约束可考虑 JSXGraph 适配器 | 教学操作、参数探索、算法回放 |
| 静态图 | 同主题导出 SVG/PNG；Matplotlib 仅离线科学图 | 讲义插图 |
| 离线视频（可选） | **独立** Manim CE 或 Remotion 工程；成品以媒体嵌入站点 | 推导叙事、无法交互的长镜头 |

**不要**把 Manim/Remotion 当 Vue 实时组件；**不要**为用视频 skill 而迁移主站框架。

扩展边界（需要时再引入依赖，并固定版本）：

- 更复杂 3D/拾取：Three.js 或 MathBox（先评估能否用现有 space3d）
- 大图网络展示：Cytoscape.js（布局坐标 ≠ 图算法结果）
- 符号/图论参考：离线 SymPy / NetworkX 生成 JSON，非必须进生产后端

## 每次制作步骤

1. 确认唯一教学目标与交付形式 → 填 `templates/module-spec.md`。
2. 读一个最接近的本站范例 + 本包 conventions；不要塞爆上下文。
3. 先得到可独立验算的数据/完整 trace，再画一帧静止状态。
4. 参数更新 → 单步/回退/复位 → 播放与公式同步。
5. 分项检查数学、交互、视觉（见 acceptance）。
6. 限定范围修复；重复失败则保留复现与证据，升级模型或人工，**禁止降低数学要求混过**。
7. 归档规格、版本、测试与代表性截图。

## 运行依赖提示

- 网页：沿用项目 Vue/Vite/KaTeX；新库进锁文件；先独立目录验证再接入。
- Manim：独立 Python 环境 + 官方安装文档；可能需 LaTeX；勿污染 Django venv。
- Remotion：独立 Node/React 工程；查运行时许可。
- 本包 `scripts/trace-player.mjs`：仅需较新 Node（structuredClone）。
