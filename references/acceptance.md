# 验收清单

自动化覆盖：`lint-module.mjs` 查色板、装饰、说明墙、纯文本公式、setInterval、监听泄漏、控件数、复位、Math.random、外部依赖；`check-render.mjs` 查标签遮挡（含标签互叠、出界）、Canvas DPR、KaTeX 解析错误、未渲染的 TeX、控制台错误、点控件/拖滑块/拖画布冒烟。下列其余条目仍需人工或数学验算。

## 嵌入简约（默认强制）

- [ ] 观感对齐本站 interactive / aside / numerical，而非独立展示站
- [ ] 无营销大标题、badge、说明书式长文
- [ ] 控件少而够用（典型：模式 + 短参数 + 复位；需要时再加单步/播放）
- [ ] 读数默认一行极简或折叠；无默认长侧栏 / 堆叠状态文案
- [ ] 公式至多一行 KaTeX（与图形同一驱动源）
- [ ] 动效服务理解，不抢课程正文阅读
- [ ] 仅用 figureTheme；未自造花哨皮肤

（独立调试页可放宽读数与 tour，但不得当作站内默认交付。）

## TeX 与防遮挡（强制）

- [ ] 模块内数学符号（公式、向量、范数、运算记号）均为 **KaTeX**，无长期纯文本冒充
- [ ] 画布数学标签为 DOM+KaTeX（或同等 TeX），非潦草 `fillText` 伪公式
- [ ] **注意事项**：符号与图形不互相遮挡；标签避开平行四边形/六面体/轨迹/向量中段/控件
- [ ] 冲突时有换侧、偏移或半透明底板；旋转/改参后仍可读
- [ ] 验收时固定至少一帧检查遮挡

## 数学

- [ ] 独立验算首态、末态与至少一处中间态
- [ ] 文案区分精确 / 数值参考 / 采样近似（需要时；嵌入页宜短）
- [ ] 迭代：关键残差或误差可见；发散可观察
- [ ] 随机：固定种子可复现；回退不重抽
- [ ] **叉乘**：`|a×b|` = 平行四边形面积；方向垂直于 a,b 平面且符合右手定则
- [ ] **混合积**：`a·(b×c)` = 平行六面体**有向**体积；符号随定向变化

## 状态与交互

- [ ] 单步、回退、复位正确（若模块提供）
- [ ] 三维：拖动只改相机；复位恢复默认视角与/或默认向量（规格写清）
- [ ] 播放到步 k 与 seek(k) 一致（若有播放）
- [ ] 参数变更取消播放并重建
- [ ] 连点与极端参数不崩溃（含共线/共面退化）

## 呈现（基础）

- [ ] 主题色与字体贴近 figureTheme
- [ ] 公式（若有）与图形同一驱动源
- [ ] 阶段可暂停并单独理解
- [ ] 无妨碍数学阅读的装饰动效

## 视觉工艺（详见 `visual-craft.md`）

- [ ] DPR 或清晰 SVG
- [ ] 图层：背景 → 淡网格 → 辅助 → 主对象 → 焦点
- [ ] 采样足够；网格极淡；面填充 alpha 克制
- [ ] 标注不压关键交点/面心；嵌入页少标；见上节「TeX 与防遮挡」
- [ ] 三维符合 `visual-craft.md` §J

## 动效（详见 `visual-craft.md`）

- [ ] ease-out / ease-in-out；生长/射出变速
- [ ] 参数切换打断旧动画
- [ ] 仅用 rAF；hidden 时暂停
- [ ] 右手定则等提示短且可关

## 工程

- [ ] 卸载清理定时器与监听
- [ ] 接入主站时相关测试/构建按范围通过
- [ ] Canvas：数据断言 + 固定状态截图
- [ ] 对照 `visual-craft.md` §0 与 §K 记录结果
- [ ] 记录已跑 / 未验证项

## 截图约定

固定种子、步骤、视口、字体、相机、是否播放。文件名含模式。
短 MP4/GIF 可选；嵌入验收以**静态模块观感 + 可交互**为主。
